# storelens — demo (beta)

Outil d'**intelligence concurrentielle e-commerce** (type TrendTrack) : catalogue,
historique de lancement, et surtout les **publicités Meta** d'une boutique — créas,
signal de scaling, timeline quotidienne.

**Démo live :** voir l'onglet GitHub Pages de ce repo.

Toutes les données affichées sont **réelles**, capturées par le moteur `storelens`
(Meta Ad Library + Shopify) :
- **Gymshark** — 12 publicités Meta réelles, 30 jours d'historique d'ads actives, répartition par pays, catalogue.
- **Allbirds / ColourPop** — catalogues réels.

Interface statique (aucun backend) — le moteur d'ingestion vit dans un repo privé.

> Beta interne. Non affilié à TrendTrack.
